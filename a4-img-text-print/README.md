# ✦ Diary Grid Maker

A beautiful browser tool to build a 4×3 grid of photos and quotes — sized to print on A4 and cut out for your diary.

## How to run

You need **Node.js** installed (any version). Then:

```bash
node server.js
```

The browser will open automatically at `http://localhost:3456`

## How to use

1. **Click any cell** in the grid to open the editor
2. **Add a photo** — upload from your computer, or paste an image URL
3. **Add a quote** — type any text and choose a sticky note colour
4. **Edit or remove** — hover over a filled cell to see edit/remove buttons
5. **Print** — click the "Print to A4" button, then cut along the dashed lines

## Tips

- The grid is 4 columns × 3 rows = **12 cells** per page
- Images are contained within their cell (no cropping)
- Sticky notes come in 5 pastel colours
- Dashed cut lines appear only when printing
- Run multiple print sessions to fill your diary!
